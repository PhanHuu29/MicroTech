# Thư mục ảnh MicroTech

Đổi ảnh bằng cách sửa đường dẫn trong `src/lib/images.ts`:
- đặt file mới vào thư mục này rồi trỏ tới `'/images/ten-file.jpg'`, hoặc
- dùng link ngoài `'https://…'`.

Hoặc ghi đè file cùng tên (ví dụ `cover.svg`) để không phải sửa code.
Kích thước gợi ý: logo-icon ~240x200 (chữ M) · logo-text ~650x120 (chữ MicroTech, nền trong suốt)· cover 1600x1000 · icon dịch vụ 256x256 · icon "Vì sao chọn" 160x160 · icon mạng xã hội 96x96.

`logo-full.png` là logo gốc đầy đủ (không dùng trên web). Favicon: `public/favicon.png`.
